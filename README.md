# Vasyworks Docker Environment

Vasyworks（賃貸管理システム）をローカル環境で瞬時に構築・実行するためのDocker統合環境です。

## 🚀 特徴
* **コマンド一発起動**: `docker compose up -d` を実行するだけで、データベースの構築から全システムの立ち上げまで全自動で完了します。
* **テストデータ自動投入**: 起動時にTESTデータが自動的にデータベースへ流し込まれるため、インストール後すぐにデモ画面を確認可能です。

## 📋 システム構成
本環境は以下のプロジェクトで構成されています。
* **vacancy_model**: VasyworksDB（データベースの定義・管理）
* **vacancy_mgr**: VasyworksMGR（物件データの登録・管理）
* **vacancy**: VasyworksLIST（自社物件の空室情報の公開）
* **vacancy_api**: VasyworksAPI（物件データ取得用のAPI）
* **vacancy_search**: VasyworksSEARCH（物件データの検索）

## 🛠 クイックスタート

### 前提条件
* Docker Desktop がインストールされていること

### 手順
1. リポジトリをクローンします。
2. コマンドプロンプト（またはターミナル）でリポジトリのルートフォルダに移動します。
3. 以下のコマンドを実行してください。
   ```bash
   docker compose up -d --build
   ```
4. 実行後、下記の要領で動作確認を行ってください。
   1) VasyworksMGR（http://localhost:8001/）をブラウザで開く。
   2) ユーザID「t-kanri」パスワード「guest1234」でログインする。
   3) メニューより「建物名検索」をクリックし、建物一覧を表示する。
   4) 「サンプルマンション」をクリックし、建物情報画面を表示する。
   5) 「基本情報」「地図」「建物画面」「部屋一覧」のタブを順番にクリックし、表示を確認する。
   6) 「部屋一覧」の「101」号室をクリックし、部屋情報画面を表示する。
   7) 「基本情報」「部屋画面」を順番にクリックし、表示を確認する。
   8) 「編集」をクリックし、部屋編集画面を表示する。
   9) 「閲覧ページへ戻る」をクリックして、部屋情報画面に戻る。
   10) 部屋情報画面と建物情報画面を閉じ、ログアウトする。
5. 各プロジェクトには、下記の各URL（ポート番号8000～8004）にてアクセスしてください。ユーザ情報は別の資料を参照してください。
* **VasyworksDB**: http://localhost:8000/admin
* **VasyworksMGR**: http://localhost:8001/
* **VasyworksLIST**: http://localhost:8002/
* **VasyworksAPI**: http://localhost:8003/
* **VasyworksSEARCH**: http://localhost:8004/
